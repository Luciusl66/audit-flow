# 实务卡片模板

提炼后正文控制在 1～2 页（约 800～1500 字）。用审计实务语言转述，标明条款或指南出处。以一个报告期与适用版本为基准。每项判断附能支持结论的证据，缺项标「待核」。避免复制法条原文和引入真实客户信息。

篇幅可按确认与计量约 300～500 字、列报约 180～300 字、风险情形约 240～450 字、人工复核约 100～200 字分配。若科目同时涉及多项准则，保留共同判断依据，并分别写明复杂事项适用的准则及过渡条件。

## 元数据

| 字段 | 填写要求 |
| --- | --- |
| 准则编号 | CAS 编号及名称。应用指南写明所配套的准则。 |
| 适用科目 | 已确认的一级科目编码、名称及相关业务边界。 |
| 最新修订年份 | 准则修订年份、报告期适用版本和必要的过渡安排。 |
| 源文件路径 | 写明准则、指南的公开链接或本地相对路径，标记适用版本及条款位置。发布版本保留可公开的出处。 |

## 一、核心确认与计量条件

- **确认**：列出触发确认、停止确认或递延确认的具体条件。写明用于判断履约、控制、权利义务或其他适用条件的凭证。
- **初始计量**：指明计量基础、纳入和剔除项，标明税额、货币单位与期间口径。
- **后续计量**：列明适用的摊销、折旧、复评、减值、转回或终止确认条件，并写清证据来源。只填该科目适用的事项。
- 若会计政策允许选择，记录选择范围、一致性要求和变更触发条件。对跨期或分阶段实施的业务，列明本期和比较期间分别采用的口径。

## 二、报表列报与重分类口径

- 写明列报项目、判断时点、抵销限制及需要拆分的辅助核算维度。
- 按「触发条件 → 借记项目 / 贷记项目 → 证据与复核」记录各项标准 RJE 方向。无法预设方向时，列出决定方向所需的判断。
- 区分报表层的 RJE 和影响账务的 AJE。保留已确认调整的范围、期间和金额依据。
- 记录复核该项重分类所需的原表位置、明细层级、报表项目及对方项目，便于从报表追溯至底稿。

## 三、审计常见雷区与舞弊高发点

- 列 3～5 项具体情形。每项至少包含可观测异常、可能错报的方向以及核查证据。
- 可从截止、分类、估计偏差、合同变更、期后冲回或关联方交易中选取适用于该科目的情形。
- 记录复核结果及反向证据。筛查信号只作为取证线索。
- 每项情形可补充一条首选程序，如查对期后收付、抽取合同变更、重算预计金额，或向独立来源获取书面确认。

## 四、不可量化的人工复核提示

- 列明需审计员判断的经济实质、合同条款、适用政策、重要性或估计假设。
- 写清需取得的证据及负责人。证据不足时保留待核事项。
- 写明结论或分录建议的复核条件。逐项区分可由机器判断的条件和需人工确认的条件。
