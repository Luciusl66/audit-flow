# 本地 CAS 原文文件名约定

将获准使用的本地原文放在此目录，使用 `.md` 扩展名。 [准则注册表](../../rules/cas_registry.yaml) 的 `raw_source_pattern` 匹配文件名。按以下格式命名，括号内可标注版本或年份。

| 文件类型 | 命名格式 | 示例 |
| --- | --- | --- |
| 基本准则 | `企业会计准则——基本准则（版本）.md` | `企业会计准则——基本准则（2014）.md` |
| 具体准则 | `企业会计准则第N号——准则名称（版本）.md` | `企业会计准则第30号——财务报表列报（2014）.md` |
| 单项应用指南 | `企业会计准则第N号——准则名称 应用指南（版本）.md` | `企业会计准则第30号——财务报表列报 应用指南（2024）.md` |
| 基本准则应用指南 | `基本准则 应用指南（版本）.md` | `基本准则 应用指南（2024）.md` |
| 通用应用指南 | `企业会计准则应用指南汇编（版本）.md` | `企业会计准则应用指南汇编（2024）.md` |
| 通用账务处理附录 | `会计科目和主要账务处理（版本）.md` | `会计科目和主要账务处理（2006）.md` |

同一准则有多个版本时，在文件名中注明年份，由复核人按主体及报告期确定适用版本。目录中的原文仅在本地保存，提交时仅保留说明和目录占位文件。
